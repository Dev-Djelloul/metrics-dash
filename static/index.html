Segmentation RFM (Récence / Fréquence / Montant)

Technique de segmentation client classique en marketing/data : chaque client reçoit un score 1-4 sur trois axes. Récence (il a acheté récemment ?) · Fréquence (il achète souvent ?) · Montant (il dépense beaucoup ?). Les scores combinés donnent un segment actionnable (Champions, À risque, Perdus...).

Analyse de cohortes (rétention)

Chaque ligne = un groupe de clients ayant acheté pour la première fois ce mois-là (la cohorte). Chaque colonne = combien de mois plus tard. La couleur montre le % de la cohorte encore active. C'est l'outil de référence pour mesurer la fidélisation dans le temps.

CA généré par cohorte

Même lecture que le tableau de rétention, mais en chiffre d'affaires plutôt qu'en % de clients actifs. Deux cohortes avec la même rétention en % peuvent valoir très différemment si l'une regroupe des clients qui dépensent plus.

Prévision de CA (régression linéaire)

Projette les prochains mois à partir de la tendance historique (régression linéaire simple, sans librairie externe). La zone bleue est l'intervalle de confiance (~95%) : elle s'élargit avec l'horizon, une prévision lointaine étant statistiquement moins fiable qu'une prévision proche.

Prévision du nombre de commandes

Même méthode que la prévision de CA, appliquée au nombre de commandes plutôt qu'au montant. Répond à « combien de ventes » plutôt qu'à « combien ça va rapporter » — les deux ne bougent pas forcément ensemble (ex : panier moyen qui grimpe).

Prévision de nouveaux clients

Projette le rythme d'acquisition de nouveaux clients par mois, à partir de la tendance historique. Utile pour anticiper si le rythme d'acquisition ralentit avant que ça se voie sur le CA.

Lexique des termes techniques

Chaque terme employé ailleurs dans le dashboard, expliqué simplement — pas besoin de tout connaître pour commencer.

MoM (Month-over-Month)
Variation du CA vs le mois précédent. Répond à : « est-ce qu'on progresse court terme ? »
YoY (Year-over-Year)
Variation vs le même mois l'an dernier. Neutralise la saisonnalité (ex : pic de décembre comparé au décembre précédent, pas à novembre).
Moyenne mobile
Moyenne calculée sur une fenêtre glissante (ex : les 7 derniers jours), qui lisse le bruit journalier pour voir la vraie tendance.
RFM (Récence / Fréquence / Montant)
Méthode CRM qui segmente les clients sur 3 dimensions comportementales : quand ils ont acheté pour la dernière fois (Récence), à quelle fréquence ils achètent, et combien ils dépensent (Montant). Chaque client reçoit un score 1-4 sur chaque axe, combinés en un segment actionnable.

L'intérêt pratique : relier chaque segment à une action marketing concrète (visible dans la colonne dédiée de l'onglet RFM) — segment → intention → action :
  • Champions : fidéliser → programme VIP, avantages exclusifs
  • Clients fidèles : entretenir → offres régulières
  • Nouveaux clients : accompagner → email de bienvenue
  • À risque : prévenir le désengagement → offre personnalisée ou rappel
  • Perdus : récupérer → campagne de réactivation
Cohorte
Groupe de clients qui partagent un point de départ commun — ici, le mois de leur tout premier achat — suivi dans le temps.
Rétention / fidélisation
% d'une cohorte encore active N mois après son premier achat. Mesure si les clients reviennent, pas juste s'ils achètent une fois.
Régression linéaire
Méthode statistique qui trace la droite collant au mieux à des points historiques, pour projeter la tendance dans le futur. Simple, mais fragile sur peu de données.
Pareto (règle du « 80/20 »)
Observation empirique : une petite part des causes (ex : 20% des clients) produit souvent une grande part des effets (ex : 80% du CA).
LTV (Lifetime Value / valeur vie client)
CA moyen généré par un client sur toute sa relation avec toi. Sert à savoir combien tu peux dépenser pour en acquérir un nouveau sans perdre d'argent.
Churn (taux d'attrition)
Part des clients qui arrêtent d'acheter. Approximé ici par le % de clients dans les segments RFM « À risque » et « Perdus ».
API
Interface de Programmation d'Application : la façon dont deux logiciels échangent des données — ici, ton dashboard interroge l'API de Stripe.
CSV
Fichier texte tabulaire (Comma-Separated Values) : le format le plus simple pour faire passer des données d'un outil à un autre — ex : vers Excel ou Power BI.

Connecter tes données à Power BI

Power BI n'a pas besoin d'un connecteur spécial : sa fonction native « Obtenir les données > Web » lit un fichier CSV en ligne directement, sans code. Dans Power BI Desktop : Accueil → Obtenir les données → Web, colle l'une des URL ci-dessous, valide — la table apparaît, prête à être mise en forme.

Quel est ton secteur d'activité ?

Stripe ne transmet aucune info sur ton activité (une transaction, c'est juste un montant, un client, une date) — cette info sert uniquement à situer tes métriques dans leur contexte.
